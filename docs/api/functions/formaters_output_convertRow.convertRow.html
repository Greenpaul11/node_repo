          T extends EntityTransformRules,

      ): EntityExtend<E, EntityAggregateAttributes<E>>

      Convert a transformed row into a fully typed entity.

      Takes a row that has already been transformed at the type level via EntityTransform and walks it attribute-by-attribute, applying the matching converter from converters and recursing into nested relations. The result is the entity in its domain / origin type representation (e.g. Date instead of string, Decimal instead of number, etc.).

      The function has two call shapes:

      • Initial call (nested omitted or undefined) — returns the full entity, optionally extended with EntityAggregateAttributes computed from converters.fns.
      • Recursive call (nested: true) — returns just the converted sub-entity for a relation, without aggregate function attributes.

      Conversion steps performed:

      1. Every base attribute listed in mappedSelect.select is looked up in converters.baseAttributes and converted when a converter exists.
      2. Each relation key in mappedSelect.subEntities is recursively converted. One-to-many relations (Array.isArray(subRows)) are mapped element-by-element; one-to-one relations are converted directly or left as nullif missing).
      3. Only on the initial call: each entry in mappedSelect.fns is converted via converters.fns and attached to the result under its canonical key (see extractFnToString).

      Type Parameters

      • E extends { active: boolean; created: Date; id: number; updated: Date }

        The typed entity shape being produced.

      • T extends EntityTransformRules

        The transformation rules driving the input row's type-level shape.

      Parameters

      • row: EntityTransform<E, T>

        The transformed row (or sub-row) from the ORM layer.

      • mappedSelect: MapEntitySelect<E>

        Select map produced by entitySelectToMapSelect. Only attributes / relations / aggregates listed here are converted.

      • converters: ConverterFunctionsInfer<E>

        Attribute converters (base + relations + aggregate) produced by buildConverters.

      Returns EntityExtend<E, EntityAggregateAttributes<E>>

      On the initial call: an EntityExtend of E and EntityAggregateAttributes<E>. On a recursive call: the converted sub-entity (E[keyof ExternalReferences<E>]).

      Example

      // Initial call — convert a root row with a relation and an aggregate
      const entity = convertRow<Product, T>(row, mappedSelect, converters)
      // => Product & { $count_prices?: number, $sum_prices_price?: Decimal }

      // Recursive call — convert a single related row (no aggregates)
      const subEntity = convertRow<Price, T>(subRow, subSelect, subConverters, true)
      // => Price
