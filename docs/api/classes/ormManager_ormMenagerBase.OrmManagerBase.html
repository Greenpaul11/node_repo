    Class OrmManagerBase<E, T, M, F>Abstract

    Base class that defines the contract every ORM manager must satisfy.

    An ORM manager wraps the raw database layer behind a small, typed CRUD surface (createOne, deleteOne, destroyAll). It exposes a single concrete instance (manager) plus the active DialectOptions, and leaves the actual database calls to subclasses that know the specifics of one ORM (Sequelize today, Prisma-ready for the future).

    Subclasses implement the abstract methods to talk to their ORM's native model API, while callers consume the typed entity shape E regardless of which ORM is underneath.

    Example

    // Minimal Sequelize-style subclass
    class OrmManager<E extends EntityBase>
        extends OrmManagerBase<E, Model<any, any>, Sequelize> {

        async createOne(
            data: EntityCreationAttributes<E, CreationOptional<E>>
        ): Promise<Model<any, any>> {
            return this.manager.create(data);
        }

        async deleteOne(id: number): Promise<boolean> {
            const n = await this.manager.destroy({ where: { id } });
            return n > 0;
        }

        async destroyAll(where?: EntityQueryable<E>): Promise<number> {
            return this.manager.destroy({ where });
        }
    }

    • E extends EntityBase

      The typed entity shape. Must extend EntityBase.

    • T

      The ORM-specific row / model type returned by createOne. Typically a Sequelize Model instance or a Prisma record. Left open (T) because every ORM has its own model type.

    • M = unknown

      The ORM-specific database manager type (e.g. a Sequelize Sequelize instance or a Prisma PrismaClient). Defaults to unknown — supply it explicitly in subclasses so manager carries a useful type.
